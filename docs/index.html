Context-aware review with RAG

Merlin can index your entire codebase and past review comments into a vector store. Before each AI call, relevant snippets are retrieved and injected into the prompt — so the AI knows your patterns, naming conventions, and past issues.

Embeddings run locally via Ollama. No embedding API cost. Five vector store backends to match any infrastructure.

local (JSONL) memory Qdrant ChromaDB Pinecone
# merlin.toml
[rag]
enabled = true
store   = "qdrant"
embed_model = "nomic-embed-text"

# One-time setup
$ ollama pull nomic-embed-text
$ docker run -p 6333:6333 qdrant/qdrant
$ merlin rag index .

# Review now has full codebase context
$ merlin review
# CLI REPL
$ merlin agent

Autonomous ReAct agent

Merlin includes a full Reason → Act → Observe agent loop. Give it a goal and it plans the steps, calls the right tools, observes the results, and iterates until done.

All slash commands are available as agent tools. The agent also has rag_search, post_comment, and get_pr_info for richer autonomous workflows.

Conversation memory persists across sessions via a JSONL ring-buffer, so the agent remembers context from earlier interactions.

Quick start

Up and running in under 5 minutes.

GitHub Actions
GitLab CI
Local
# .github/workflows/review.yml
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  merlin-review:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - run: |
          curl -L https://github.com/you/merlin/releases/latest/download/merlin-linux-amd64 -o merlin
          chmod +x merlin && ./merlin review
        env:
          GITHUB_TOKEN:      ${{ secrets.GITHUB_TOKEN }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

Then, optionally enable RAG for context-aware reviews

# merlin.toml (add to your repo root)
[rag]
enabled     = true
store       = "local"   # zero infrastructure
embed_model = "nomic-embed-text"

# Then index once:
$ ollama pull nomic-embed-text
$ merlin rag index .
